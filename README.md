# RSproject
This project aims to develop a context-aware hybrid recommender system for Thai performing arts by integrating natural language processing and machine learning techniques. The pipeline begins with customized word tokenization and noun extraction, followed by embedding using WangchanBERTa, and clustering keywords using K-Means with UMAP. Proportional keyword selection is applied to ensure diverse and meaningful representation. The recommendation engine combines Content-Based Filtering and SVD-Tuned Collaborative Filtering, enhanced with contextual weighting and interpretable explanations. Evaluation results demonstrate that the hybrid model outperforms standalone approaches in ranking quality, making it a promising solution for promoting access to Thailand’s cultural heritage in the digital age.
